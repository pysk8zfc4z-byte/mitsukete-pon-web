# みつけてポン （ビルド成果物）

積まれた色ブロックの下端を、手元の同じボタンで消す30秒スコアアタック。
いろ・かたち・いくつの3モード。幼児から小学校低学年まで。

**あそぶ: <https://pysk8zfc4z-byte.github.io/mitsukete-pon-web/>**

このリポジトリは公開用のビルド出力だけを置いている。ソースと仕様書は別の非公開リポジトリ。
手で編集しない。`npm run deploy` で丸ごと入れ替わる。

- 個人使用。課金・広告・アカウント・解析なし
- **外部通信を一切しない。**設定も写真もブラウザの localStorage だけに残る
- 配布物に画像を1枚も含まない。すべて Canvas にコードで描いている（アイコンも生成）
- じゆうモードで使う写真は**端末の中だけ**に保存され、どこにも送らない
- 一度開けばオフラインでも起動する（Service Worker）
